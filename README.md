# Engineering Portfolio

Здесь собраны **реальные прикладные проекты**, которые я развивал не как учебные упражнения, а для решения конкретных задач: автоматизация контент-пайплайна, браузерное расширение и эксплуатация Linux-инфраструктуры.

Исходники части проектов остаются приватными из-за runtime-конфигурации, интеграций и инфраструктурных деталей. В этом репозитории — безопасные case studies: архитектура, стек, инженерные задачи, проверки качества и принятые решения.

## Проекты

| Проект | Задача | Основной стек |

| [**Anime Factory**](docs/anime-factory.md) | Автоматизированный pipeline поиска, анализа, рендера и публикации коротких видео | Python, asyncio, SQLAlchemy, FFmpeg, YouTube API, Telegram |
| [**PageKeeper**](docs/pagekeeper.md) | Браузерное расширение для сохранения веб-страниц в PDF и редактируемый Word | JavaScript, Chrome Manifest V3, browser APIs |

## Что мне важно в инженерной работе

- не только написать код, но и довести решение до рабочего состояния;
- разделять исходники, конфигурацию, runtime-данные и секреты;
- делать воспроизводимый запуск и понятную структуру проекта;
- добавлять автоматические проверки там, где они реально защищают от ошибок;
- документировать архитектуру и эксплуатацию, а не оставлять проект «только у себя в голове».
