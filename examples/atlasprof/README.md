# AtlasProf — безопасные примеры

Эта папка не является копией командного production-репозитория. Здесь лежат небольшие очищенные примеры, показывающие архитектурные паттерны проекта без чужой Git-истории и приватных данных.

## Что посмотреть

- [flask_routes.py](flask_routes.py) — серверная страница и JSON API;
- [knowledge_search.py](knowledge_search.py) — простой слой поиска по базе знаний.

## Реальная структура, на которую опирается кейс

```text
atlas/
├── app.py
├── auth.py
├── db.py
├── templates/
├── static/
├── wiki/
└── react_frontend/build/
```
