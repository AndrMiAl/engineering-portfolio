# PageKeeper

**Тип:** рабочее браузерное расширение
**Текущая версия исходников:** 1.19.0
**Задача:** сохранять веб-страницы в PDF и Word так, чтобы результат был не просто «скриншотом страницы», а пригодным документом.

## Что умеет

### PDF

- сохранять настоящий текстовый слой;
- оставлять текст доступным для поиска и копирования;
- сохранять визуальное оформление страницы.

### Word

- формировать редактируемый документ;
- сохранять заголовки, таблицы, изображения и ссылки;
- поддерживать режимы результата от максимально точного до более чистого и редактируемого.

## Особенность задачи

Обычная веб-страница может быть длинной, динамической или виртуализированной. Например, чаты и почтовые ленты часто держат в DOM только текущую область просмотра. Поэтому расширению приходится отдельно решать задачу последовательного сбора содержимого и формирования итогового документа.

Для разных сценариев предусмотрены режимы съёмки с browser APIs и fallback-вариант через обычную прокрутку.

## Приватность

Обработка содержимого страницы выполняется локально в браузере. Сохраняемый контент не требуется отправлять на сторонний сервер.

## Качество

Для версии 1.19.0 зафиксированы **42 сценария проверки**, включая реальные страницы Wikipedia, MDN и example.com.

GitHub Actions дополнительно проверяет:

- корректность `manifest.json`;
- Manifest V3;
- совпадение `version` и `version_name`;
- синтаксис JavaScript-файлов.

## Почему исходники пока приватные

Проект остаётся рабочим и развивается отдельно. В публичном портфолио я показываю архитектуру, функции и подход к качеству, не открывая код автоматически только ради видимости на GitHub.
