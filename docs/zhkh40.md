# ЖКХ40

**Тип:** командный рабочий проект на Flask.

Веб-сервис по вопросам ЖКХ: база знаний, сценарии помощи пользователю, расчёты, шаблоны документов и административная часть.

## Возможности проекта

- база знаний по вопросам ЖКХ;
- чат-сценарии и подбор ответов;
- калькуляторы коммунальных ресурсов;
- шаблоны заявлений и документов;
- генерация DOCX и подготовка печатного представления;
- административная панель;
- полнотекстовый/сценарный контент и статические материалы.

## Мой подтверждённый вклад по истории проекта

- развитие административной панели;
- доработка главной страницы, страницы «О нас» и чата;
- удобный просмотр Word-документов;
- доработка DOCX preview;
- правки интерфейса и CSS;
- подключение шрифтов для корректного формирования документов.

## Стек

**Python · Flask · JavaScript · HTML/CSS · DOCX generation · TF-IDF в командном проекте**

Исходный репозиторий командный, поэтому в профиле используется case study вместо копии чужого репозитория.
