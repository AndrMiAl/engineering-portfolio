# AtlasProf — Атлас профессий

**Тип:** командный рабочий веб-проект.

Система объединяет карту направлений, страницы подразделений и профессий, образовательные траектории, медиа, базу знаний и административную часть.

## Что есть в проекте

- карта и навигация по направлениям;
- страницы подразделений и профессий;
- карьерные и образовательные траектории;
- база знаний с категориями, поиском и вложениями;
- административные интерфейсы;
- роли пользователей и управление учётными записями;
- работа с изображениями, видео и документами;
- React-сборка для части интерфейса карты.

## Стек

- Python / Flask;
- PostgreSQL;
- React / JavaScript;
- HTML/CSS;
- bcrypt и role-based access;
- Markdown и файловые вложения.

## Почему в портфолио case study, а не копия репозитория

Проект командный. В публичном профиле я не дублирую репозиторий команды и не приписываю себе чужую Git-историю — показываю сам проект и его инженерный контекст отдельно.
