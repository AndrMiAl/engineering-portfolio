# n8n Automation

**Тип:** production-автоматизация, используемая вместе с Python-сервисами.

n8n используется не как отдельная учебная демка, а как orchestration-слой для реального pipeline: запуск шагов, связка сервисов, обработка событий и управление цепочкой публикации.

## Где применяется

Основной сценарий связан с контентным pipeline: Python-сервисы выполняют тяжёлую бизнес-логику и обработку медиа, а n8n связывает этапы автоматизации и внешние интеграции.

## Что даёт такая схема

- визуальная оркестрация workflow;
- связка Python-сервисов через API/commands;
- повторяемые сценарии запуска;
- разделение тяжёлой логики и orchestration;
- удобное управление цепочкой без переноса всей логики в low-code;
- запуск как отдельного Linux-сервиса с restart policy.

## Стек

**n8n · Python · REST/API · Linux · systemd · automation · external integrations**

## Принцип

n8n отвечает за orchestration, а код, обработка данных и media pipeline остаются в обычных Python-компонентах. Это позволяет использовать low-code там, где он удобен, не превращая весь проект в набор непрозрачных workflow.
